# it-professional-elective-1 

-
- FreshNest: Online Laundry Service using python
- Web interface built with Flask, Jinja2, HTML, CSS and JavaScript (no tkinter)
- SQLite database accessed through Python's built-in sqlite3 module
- Payments with method selection (cash, GCash, card) and printable receipts
- Online booking
- 2 roles: admin and customer
- use Lists and dicts
- use Functions and modules: one function per action, with json, datetime
- use File I/O saved to a .json so they persist between runs
- use Exceptions: try/except handles a missing or corrupted data file, bad dates and save errors.
